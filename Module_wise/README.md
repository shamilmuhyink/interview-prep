## 🔥 How to Use This Kit

1. **Start with Critical questions** (top 5 per module, tagged 🔴) — these appear in 80%+ of real interviews.
2. **Work through remaining questions** in order — they're sorted by decreasing interview frequency.
3. **Practice code snippets** — type them out, don't just read. Interviewers notice fluency.
4. **Understand trade-offs** — every answer covers pros/cons. Senior-level interviews reward nuanced thinking.
5. **Mock interview** — pick 2 random questions per module for a 45-minute simulation.

Every question in this kit is tagged with where it is most commonly asked:

| Tag | Meaning | Example Companies |

> **Note on Service-Based Companies:** Indian service companies tend to focus heavily on fundamentals — OOP concepts, collections internals, SQL query writing, basic Spring lifecycle, and definition-style questions. Product companies lean into system design, concurrency edge cases, and algorithmic problem-solving. Questions tagged 🌐 **Both** are universal and appear everywhere.
